# ProductoManager

Teste técnico: tela de gerenciamento de produtos (listar, criar, editar, remover), consumindo a API fornecida.

## Stack

- Next.js (App Router)
- React Server Components + Server Actions
- Tailwind CSS
- Axios

## Como rodar

```bash
npm install
npm run dev
```

Abre em `http://localhost:3000`.
